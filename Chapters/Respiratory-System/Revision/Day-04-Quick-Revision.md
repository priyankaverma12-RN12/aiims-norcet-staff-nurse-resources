# Day 4 — Respiratory completion quick revision

[Chapter](../README.md) · [Grand mock](../MCQs/Respiratory-System-Grand-Mock-50.md) · [Previous Year Questions](../Previous-Year-Questions/Day-04-Reported-Exam-Leads.md) · [References](../References.md)

| Clue | Recall |
|---|---|
| Pneumonia | Alveolar infection/exudate; HAP ≥48 h after admission if not incubating |
| NTEP drug-sensitive standard | 2HRZE + 4HRE, exceptions apply |
| H/R/Z/E adverse effects | Neuropathy / orange fluids / hyperuricemia / optic neuritis; hepatotoxicity H/R/Z |
| TB precautions | Airborne, staff N95, patient mask for necessary transport |
| Mantoux | Intradermal; 48–72 h; measure induration, not redness |
| Pleural effusion / pneumothorax | Fluid/dull vs air/hyperresonant; tension emergency |
| Chest drainage | Below chest, kink-free, continuous water-seal bubbling may mean leak; no routine clamping |
| Respiratory failure | Type I low O2 with normal/low CO2; type II high CO2 |
| ARDS | Permeability edema; P/F 200–300 mild (strictly >200), >100–200 moderate, ≤100 severe with classic Berlin other criteria |
| PE | Perfusion block, DVT risk, sudden dyspnea, emergency if hypotensive |
| Ventilator modes | A/C full preset support; SIMV synchronized mandatory plus spontaneous; PSV supports initiated breaths |
| CPAP / bilevel | One pressure / IPAP and EPAP |
| PEEP | End-expiratory positive pressure |
| High / low alarm | Resistance/stiffness vs leak/disconnect; assess patient first |
| Auto-PEEP | Incomplete exhalation; team evaluates longer expiration |
| ETT | Waveform capnography confirms placement, CXR depth |
| Tracheostomy | Obturator remove; cuff 20–30 cm H2O; humidification, emergency spare tubes |
| Suction | ≤15 sec; preoxygenate as indicated; stop for bradycardia/desaturation |
| VAP | HOB 30–45° if safe, toothbrushing/oral care, daily liberation readiness |
| Atelectasis | Alveolar collapse; incentive spirometer = inhale |
| CPT | Percussion, vibration, gravity drainage for retained secretions |
| Pulmonary edema | LV pressure or permeability; pink frothy sputum possible |
| Bronchiectasis | Irreversible dilated bronchi; HRCT; secretion clearance |
| Abscess / empyema | Pus within lung / in pleura |
| Lung cancer | Small cell SIADH/ACTH; squamous PTHrP; Pancoast Horner |
| Flail chest | Paradoxical movement; associated contusion |
| Hemoptysis | Cough blood; airway priority in massive bleeding |
| OSA | Obstruction despite effort; AHI; CPAP |
| Fibrosis | Stiff lungs, restrictive pattern |
| Occupational | Silica/TB, asbestos/mesothelioma, cotton/byssinosis |
| CF | AR CFTR chromosome 7, sweat chloride ≥60 supports diagnosis |
| Epistaxis | Forward lean, pinch soft nose |
| Epiglottitis | Airway emergency; no forced examination |
| V/Q | Normal overall ~0.8; shunt zero; dead space no perfusion |
| AV | (TV − dead space) × RR |
| Bohr / Haldane | CO2/pH promotes O2 unloading / O2 binding promotes CO2 release |
| Winter | Expected PaCO2 = 1.5×HCO3+8±2 |
| Allen | Ulnar collateral hand flow; local protocol |
| Cheyne-Stokes / Kussmaul | Cyclic crescendo-decrescendo + apnea / deep breathing in metabolic acidosis |

Clinical values exam guides, not independent bedside prescriptions. Practice pending.
