| Exam clue | Answer |
|---|---|
| Variable airway obstruction | Asthma |
| Persistent airflow obstruction | COPD |
| Silent chest in severe asthma | Emergency |
| Productive cough 3 months × 2 years | Chronic bronchitis |
| Alveolar wall destruction | Emphysema |
| Blue Bloater / Pink Puffer | Chronic bronchitis / emphysema (classic) |
| Rapid bronchodilator | Salbutamol |
| ICS side effect | Oral candidiasis |
| COPD exacerbation initial oxygen target | Usually 88–92%, if hypercapnia risk |
| Precise FiO2 | Venturi mask |
| Emergency high-concentration mask | NRBM |
| Liquid medicine to mist | Nebulizer |
| Air trapping | Pursed-lip breathing |
| Room air | 21% |

**Flow:** Cannula 1–6; simple mask 5–10 (some protocols 6–10); NRBM 10–15 L/min; Venturi adapter-specific. FiO2 approximate for variable devices.
