## Import and review rules

Jab koi naya external test add hota hai, uska source name, question order aur original options preserve karna hai, jahan reproduction permitted ho. Source ka answer key agar available nahi hai, toh clinically reviewed answer ko suggested answer label karna hai. Har option ka reason simple Roman Hinglish mein samjhana hai aur exam clue, difficulty label, evidence aur video verification status add karna hai. Agar original question outdated ya ambiguous hai, toh uski correction ko alag note mein explain karna hai. Original source ko silently change nahi karna hai.

Existing file paths, learner attempts and question identities must remain unchanged. External question slots must never be counted as new AI-authored topic-bank originals, mock-exclusive originals or authenticated PYQs. New public copies of third-party materials require appropriate reproduction rights.
