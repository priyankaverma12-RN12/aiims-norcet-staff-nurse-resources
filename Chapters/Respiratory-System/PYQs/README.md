## Clear source labels — exam prep mein bahut important

- **Scanned past paper (third-party host):** Numbered historical question identifiable in a scanned question booklet. Government-hosted/authenticated source hona zaroori nahi. Exact number **booklet series** ke hisaab se mention karenge.
- **Memory-based NORCET:** Candidates ki recall/secondary compilation. Original CBT question exact verify nahi hua. **Official verified PYQ nahi**.
- **Original practice MCQ:** Humne study ke liye banaya; koi past exam provenance claim nahi.

### User-friendly rules

1. Past question **kis exam/year/booklet** ka hai, clearly mention karo.
2. Original **source link + question number** jahan available ho, add karo.
3. Hinglish mein apni explanation + why others wrong add karo.
4. **Official vs scanned third-party vs memory-based** kabhi mix mat karo.
5. Jis topic ko abhi padha nahi, uski PYQ abhi mat add karo.
