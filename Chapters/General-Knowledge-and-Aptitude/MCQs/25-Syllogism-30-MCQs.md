# 📝 Syllogism — 30 original logic MCQs

**Study-ready, unattempted.** Original practice, not Previous Year Questions. Treat the statements as true. Categories may be empty unless existence is explicit or implied by a particular statement. Some means at least one. Only a few means some but not all. Only A are B means all B are A. A possible conclusion needs at least one arrangement consistent with all premises. A necessary conclusion must hold in every arrangement.

### Q1. Given All A items are B items. All B items are C items. Which conclusion must follow?

**Difficulty:** 🟡 Medium · **Priority:** 🟠 HIGH YIELD · Original practice

- **A.** No A items are C items
- **B.** All A items are C items
- **C.** Some A items are C items
- **D.** All C items are A items

<details><summary>✅ Sahi answer aur explanation dekho</summary>

**Correct answer: B. All A items are C items**

**Kyun sahi hai:** A B ke andar hai aur B C ke andar hai. Isliye A ka koi member C ke bahar nahi ho sakta.

**Baaki options kyun galat hain?**

- **A.** Is conclusion ka guaranteed hona zaroori nahi. Ek valid counterexample hai: object 1: A aur B aur C mein. Is arrangement mein premises true hain lekin ye conclusion false hai.
- **C.** Is conclusion ka guaranteed hona zaroori nahi. Ek valid counterexample hai: object 1: kisi listed category mein nahi. Is arrangement mein premises true hain lekin ye conclusion false hai.
- **D.** Is conclusion ka guaranteed hona zaroori nahi. Ek valid counterexample hai: object 1: C mein. Is arrangement mein premises true hain lekin ye conclusion false hai.

**Exam trick:** Ek bhi valid counterexample mil jaaye toh conclusion necessary nahi hai.
