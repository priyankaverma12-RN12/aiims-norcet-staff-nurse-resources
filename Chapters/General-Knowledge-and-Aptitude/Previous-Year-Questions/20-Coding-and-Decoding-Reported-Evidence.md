### Q1. Using the same alphabet-position sum rule that gives READ a code of 28, what code is assigned to HEAR?

**Difficulty:** 🟢 Easy · **Priority:** 🟠 HIGH YIELD · **🔵 SGPGI Staff Nurse, 28 February 2024, shift 1 — retrieved third-party report**

- **A.** 28
- **B.** 32
- **C.** 30
- **D.** 33

<details><summary>✅ Sahi answer aur explanation dekho</summary>

**Correct answer: B. 32**

A=1 se Z=26 tak positions use karte hain. READ mein 18+5+1+4=28 hai. HEAR mein H=8, E=5, A=1 aur R=18 hai. Sum 8+5+1+18=32 hai.

- **A.** 28 given example READ ka code hai.
- **C.** 30 correct sum se 2 kam hai.
- **D.** 33 ek extra unit add karta hai.

**Exam trick:** Har letter ki actual position likhkar sum verify karo.

### Q2. A word is coded as the square of its number of letters, so that an eight-letter word has code 64 and a six-letter word has code 36. What is the code for SUNFLOWER?

**Difficulty:** 🟢 Easy · **Priority:** 🟠 HIGH YIELD · **🔵 DSSSB Nursing Officer, 27 August 2019, shift 3 — retrieved third-party report**

- **A.** 9
- **B.** 72
- **C.** 81
- **D.** 100

<details><summary>✅ Sahi answer aur explanation dekho</summary>

**Correct answer: C. 81**

SUNFLOWER mein S,U,N,F,L,O,W,E,R total 9 letters hain. Rule length ka square hai. Isliye 9²=81 hai. Letter positions add nahi karni hain.

- **A.** 9 sirf letters ka count hai, square nahi.
- **B.** 72=8×9 hai, lekin rule 9×9 hai.
- **D.** 100 ten-letter word ka code hoga.

**Exam trick:** Word length aur alphabet-position sum different coding rules hain.
