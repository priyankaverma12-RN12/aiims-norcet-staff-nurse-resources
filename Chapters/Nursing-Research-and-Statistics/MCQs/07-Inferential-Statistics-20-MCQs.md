### Q1. A new handover protocol has no real effect on omitted information, but a study concludes that it reduces omissions. Which statistical error occurred?

**Difficulty:** 🟡 Medium · **Priority:** 🟠 HIGH YIELD · Original exam-style practice

- **A.** Type II error
- **B.** Sampling frame error
- **C.** Type I error
- **D.** Correct rejection

<details><summary>Answer aur easy explanation dekho</summary>

**Correct: C. Type I error**

**C.** True null ko reject kar diya gaya hai. Yahi false positive ya Type I error hota hai.

**Baaki options kyun galat hain?**

- **A.** Type II mein false null reject nahi hota. Is case mein true null reject hua hai.
- **B.** Sampling frame coverage ki problem ho sakti hai, lekin given statistical decision ko Type I error classify karte hain.
- **D.** Correct rejection tab hota hai jab null false ho. Yahan actual effect nahi hai.

- **C.** True positive
- **D.** Proof of equivalence

<details><summary>Answer aur easy explanation dekho</summary>

**A.** False null ko reject na karna Type II error hai. Small sample aur high variability detection ko difficult bana sakte hain.

**Baaki options kyun galat hain?**

- **B.** Type I mein true null reject hota hai. Yahan false null reject nahi hua.
- **C.** True positive mein actual effect detect hota hai. Study effect detect nahi kar paayi.
- **D.** Nonsignificant result equivalence prove nahi karta. Equivalence ke liye appropriate design aur margin chahiye.

### Q3. A study is designed with 90% power for a prespecified effect size. What is the corresponding Type II error probability under the design assumptions?

**Difficulty:** 🟡 Medium · **Priority:** 🟠 HIGH YIELD · Original exam-style practice

- **A.** 0.90
- **B.** 0.05
- **C.** 0.01
- **D.** 0.10

<details><summary>Answer aur easy explanation dekho</summary>

**Correct: D. 0.10**

**D.** Power = 1 − beta. Isliye beta = 1 − 0.90 = 0.10, specified effect aur assumptions ke liye.

**Baaki options kyun galat hain?**

- **A.** 0.90 power hai, beta nahi. Beta complementary probability hai.
- **B.** 0.05 commonly alpha set hota hai, lekin alpha aur beta alag errors represent karte hain.
- **C.** 90% power se 1% beta derive nahi hota. Complement 10% hai.

### Q4. An investigator reports p = 0.03 for a prespecified two-sided test using alpha = 0.05. Which interpretation is statistically appropriate?

**Difficulty:** 🔴 Difficult · **Priority:** 🟠 HIGH YIELD · Original exam-style practice

- **A.** There is a 3% probability that the null hypothesis is true
- **B.** The observed result is statistically significant at the specified level
- **C.** The intervention has a 97% chance of benefiting each patient
- **D.** The effect must be clinically important

<details><summary>Answer aur easy explanation dekho</summary>

**Correct: B. The observed result is statistically significant at the specified level**

**B.** P-value 0.05 se chhoti hai, isliye specified null reject kar sakte hain under test assumptions. Clinical relevance alag assess karni hogi.

**Baaki options kyun galat hain?**

- **A.** P-value null ki posterior probability nahi hai. Yeh null assumptions mein observed ya more extreme statistic ki probability hai.
- **C.** 1 − p individual benefit ki probability nahi hai. Treatment effect aur individual risk separate quantities hain.
- **D.** Statistical significance sample size aur variability par bhi depend karti hai. Effect magnitude aur harms examine karne chahiye.

<details><summary>Answer aur easy explanation dekho</summary>

**D.** Entire interval negative hai, so zero difference compatible values mein nahi hai at this confidence level. Estimated magnitude aur applicability ko bhi consider karo.

**Baaki options kyun galat hain?**

- **A.** Negative sign effect direction show karta hai, absence of significance nahi. Null value zero interval se bahar hai.
- **B.** Confidence interval population effect estimate ki uncertainty hai, individual outcomes ka prediction interval nahi.
- **C.** Point estimate uncertain hai. Confidence interval isi uncertainty ko express karta hai.

### Q6. A team wishes to estimate a population mean more precisely. If the standard deviation stays constant and an independent random sample increases from 25 to 100, how does the standard error of the mean change?

**Difficulty:** 🔴 Difficult · **Priority:** 🟠 HIGH YIELD · Original exam-style practice

- **A.** It becomes half as large
- **B.** It becomes one quarter as large
- **C.** It doubles
- **D.** It remains identical

<details><summary>Answer aur easy explanation dekho</summary>

**Correct: A. It becomes half as large**

**A.** SE = s/√n. Denominator 5 se 10 ho gaya, so same SD par SE half ho jata hai.

**Baaki options kyun galat hain?**

- **B.** Sample size four times hua, lekin SE square root of n par depend karta hai. Fourfold reduction variance of mean mein hoti hai.
- **C.** Larger independent sample mean estimate ki random variability generally reduce karta hai. Yahan square root denominator double hua hai.
- **D.** SD unchanged hone se SE unchanged nahi hota. SE sample size ko account karta hai.

### Q15. A scatter plot of two numerical mobility-performance measures shows an approximately linear increasing pattern, with Pearson r = 0.75. Which interpretation is appropriate?

**Difficulty:** 🔴 Difficult · **Priority:** 🟠 HIGH YIELD · Original exam-style practice

- **A.** Exactly 75% of the variation in one measure is explained by the other
- **B.** Increasing the first score necessarily causes an increase in the second
- **C.** There is a positive linear association in the observed sample
- **D.** The slope of the fitted regression line must be 0.75

<details><summary>Answer aur easy explanation dekho</summary>

**Correct: C. There is a positive linear association in the observed sample**

**C.** Positive sign batata hai ki higher values generally saath increase karti hain. Magnitude appreciable linear association suggest karta hai, lekin individual predictions perfect nahi hain.

**Baaki options kyun galat hain?**

- **A.** Correlation coefficient r proportion of explained variance nahi hai. Simple linear regression with intercept mein r squared = 0.5625, yani 56.25% hota hai.
- **B.** Correlation association measure karta hai. Causal conclusion ke liye temporality, confounding aur appropriate design assess karna zaroori hai.
- **D.** Regression slope measurement units aur dono variables ki standard deviations par depend karti hai. Dimensionless r se slope necessarily equal nahi hai.
