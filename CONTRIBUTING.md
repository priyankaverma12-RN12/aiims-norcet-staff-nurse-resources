# Contributing to the nursing study library

Thank you for helping make this resource accurate, readable and useful.

## Chapter format

Keep every topic separated:

```text
Respiratory-System/
  Day-01-Anatomy-Physiology/
    Topics/
      01-Topic-Name/
        Concepts/notes.md
        MCQs/practice.md
    Revision/quick-revision.md
    MCQs/final-mock-15.md
```

## Quality checklist

1. Use simple English, adding brief Hindi explanations where helpful.
2. Explain concepts before introducing their MCQs.
3. Make all questions medically correct, clinically sensible and unambiguous.
4. Check numerical calculations, units, reference ranges and answer keys.
5. Put answers under `<details>` so readers can try questions first.
6. If you cannot confirm a question's origin from an actual exam paper, label it **original NORCET-style practice**. Never claim a made-up MCQ is an AIIMS PYQ.
7. Use original diagrams (SVG preferred), or properly licensed images with attribution. Do not copy copyrighted textbook figures.
8. Distinguish a topic that was *introduced* from one that was *fully studied*.
9. Use official sources for examination schedule/pattern information, and accepted medical sources for clinical facts.
10. Avoid publishing personal health details, private test scores or identifiable student information without permission.
