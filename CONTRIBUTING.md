# How to add nursing chapters & topics

Only publish **actually studied content**. Add a new chapter under `Chapters/<Chapter-Name>/` when it is studied.

```text
Chapters/<Chapter-Name>/
  README.md
  Topics/<Study-Day>/<Topic-Name>/
    Concepts/notes.md
    MCQs/practice.md
  Day-XX/Revision/quick-revision.md
  Day-XX/MCQs/mock.md
  Assets/
  References.md
```

Rules: separate concepts and MCQs by topic; use readable English with short Hindi aids; verify clinical claims, math and answer keys; use original/licensed diagrams; describe uncompleted study as introductory; distinguish new exam-style questions from actual verified past-year questions; never include private patient data. Update chapter index and root index when content is added.
