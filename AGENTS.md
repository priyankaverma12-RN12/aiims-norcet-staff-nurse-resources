# AGENTS.md — instructions for AI assistants working on this repository

## Before ANY nursing notes, MCQ, videos, diagrams or previous-paper publication

**Read the canonical skill first:** [Nursing Study GitHub Publisher](.github/skills/norcet-staff-nurse-github-publisher/SKILL.md). It is the authoritative, detailed workflow.

Quick high-priority requirements:
- Trigger: User says **"push this to GitHub"** (or equivalent) after studying nursing content: research what they actually covered; **publish** to this repo when authorized.
- **Only previously studied topics**; no empty chapters / unstudied advanced topics.
- Simple navigation: \`Chapters/<Chapter>/Concepts/\` and matching \`MCQs/\` with **two to four related topics per substantial descriptive Markdown file**; \`Previous-Year-Questions/\`, \`Revision/\`, \`Assets/\`, \`References.md\`.
- **Concepts = simple Hinglish for a fresher; medical terms English. MCQ questions AND A/B/C/D options = exact original English wording.** Keep explanations detailed Hinglish.
- **Difficulty on every question:** \`Easy\` / \`Medium\` / \`Difficult\`; aim for appropriate NORCET and HP Staff Nurse level. Deep reasoning and why other choices are wrong.
- Research **official exam sources + medical references + coaching websites + YouTube teaching videos + YouTube MCQ-solving videos**; verify specific links and include both video columns in topic tables.
- **Previous Year Questions** only if traceable. Clearly distinguish official/third-party scanned/memory-based; never create fake verified past questions or bulk-copy copyrighted papers.
- Add original medically accurate **diagrams**, optional animation when useful, inline in notes; check all navigation links and source provenance.
- **Actually push** and verify remote commit; don't say publishing succeeded without confirmation.
- This \`AGENTS.md\` and Copilot instructions are pointers; **skill is canonical**.
